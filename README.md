<h1 align="center">🏨 Hotel Management System</h1>

<p align="center">
  <b>C++ • Console Application • Menu-Driven Program</b>
</p>

<p align="center">
  A console-based C++ program for managing room allocation,
  food orders, sales, and daily collection.
</p>

<hr>

<h2>📌 About the Project</h2>

<p>
This project is a <b>console-based Hotel Management System</b>
developed in C++.
</p>

<p>
It provides a menu-driven interface to manage available rooms,
process food orders, track sold quantities, and calculate the
total daily collection.
</p>

<h2>✨ Features</h2>

<ul>
  <li>🏨 Manage available hotel rooms</li>
  <li>🛏️ Allocate rooms to customers</li>
  <li>🍝 Manage food orders</li>
  <li>🍔 Handle burger, pasta, noodles, and shake orders</li>
  <li>📦 Track available and sold quantities</li>
  <li>💰 Calculate item-wise sales</li>
  <li>📊 Display daily sales and collection</li>
  <li>🖥️ Menu-driven console interface</li>
</ul>
